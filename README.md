# Hospital Management Knowledge Repository

## Introduction
This repository contains structured knowledge
about a Hospital Management System.

It organizes hospital-related information into
entities, attributes, relationships, facts, and
business rules.

## Objectives
- Organize hospital management knowledge.
- Identify important entities and their attributes.
- Define relationships between entities.
- Store facts and business rules.
- Support rule-based decision-making.

## Main Modules
1. Patient Management
2. Doctor Management
3. Appointment Management
4. Medical Records
5. Prescription Management
6. Hospital Billing
7. Room Management

## Tools Used
- GitHub
- Markdown
- Visual Studio Code

## Application
This knowledge repository can be used as a
reference for developing a Hospital Management
Knowledge-Based System.
