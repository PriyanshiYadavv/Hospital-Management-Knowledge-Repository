# Business Rules

R1: IF a doctor is available
    THEN the appointment can be confirmed.

R2: IF a doctor is unavailable
    THEN the appointment cannot be confirmed.

R3: IF a hospital room is available
    THEN the room can be allocated.

R4: IF a hospital room is occupied
    THEN the room cannot be allocated.

R5: IF a patient has a high fever
    THEN the patient should be referred for medical evaluation.

R6: IF consultation and medicine charges are provided
    THEN the total bill can be calculated.

R7: IF a patient is admitted
    THEN an available hospital room may be assigned.

R8: IF a prescription is created
    THEN medicine and dosage details must be recorded.
